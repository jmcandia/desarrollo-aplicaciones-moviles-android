# Registro de cambios

Todas las modificaciones notables de este proyecto se documentarán en este archivo.

El formato se basa en [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/) y este proyecto se adhiere a [Semantic Versioning](https://semver.org/lang/es/spec/v2.0.0.html).

## [Sin publicar]

## [0.2.0] - 2026-10-11

### Añadido

- Documento de especificación editorial y contrato pedagógico (`AGENTS.md`) con las directrices de contenido para las Unidades 1, 2 y 3, normas didácticas y alcance de ParkFlow.
- Guía de desarrollo y contexto para el asistente de IA (`CLAUDE.md`).
- Archivo de contexto optimizado de alta densidad para LLMs (`CONTEXT.md`).
- Configuración completa de navegación y extensiones en `mkdocs.yml` (paletas de color, soporte para diagramas Mermaid, resaltado de código y estructura modular del libro).
- Estilos CSS personalizados (`docs/assets/css/custom.css`) y script para comportamiento de menú en acordeón (`docs/assets/js/custom.js`).

## [0.1.0] - 2026-10-11

### Añadido

- Inicialización del repositorio y estructura base del proyecto para MkDocs.
- Archivo de configuración básica `mkdocs.yml` y página inicial de documentación `docs/index.md`.
- Flujo de integración continua en GitHub Actions (`.github/workflows/deploy-docs.yaml`) para compilación estricta y despliegue a GitHub Pages.
- Dependencias de Python en `requirements.txt` (`mkdocs` y `mkdocs-material`).
- Licencia del proyecto (MIT en `LICENSE`).
- Archivo `README.md` con descripción general e instrucciones de inicio local.
- Configuración de exclusiones de Git en `.gitignore`.
- Configuración de extensiones en `.vscode/settings.json`.
